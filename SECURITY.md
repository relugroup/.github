
# Security Policy

## Reporting a Security Issue

Please do not report security vulnerabilities through public GitHub issues.

If you discover a potential security issue in a ReluGroup repository, report it privately to the ReluGroup engineering team.

Include, where possible:

- the affected repository or component;
- a description of the issue;
- steps to reproduce it;
- potential impact;
- any suggested remediation.

Please avoid publicly disclosing the vulnerability until it has been reviewed and addressed.

## Sensitive Information

Do not commit:

- passwords;
- API keys;
- access tokens;
- credentials;
- private certificates;
- production secrets;
- customer-sensitive information.

Secrets must be managed using the approved environment or secret-management system.
